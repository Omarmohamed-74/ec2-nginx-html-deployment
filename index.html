Project Description

This project demonstrates deploying a static HTML web application using Docker. The application is containerized with Nginx, allowing it to run consistently across different environments.

The Docker image is built using a lightweight base image, and the application is served through a web server inside the container. This setup highlights core DevOps practices such as containerization, portability, and simple deployment workflows.

The project can be easily extended to integrate CI/CD pipelines, cloud deployment, and scaling strategies in real-world scenarios.
