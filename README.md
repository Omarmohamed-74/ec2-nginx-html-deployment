# HTML Docker Deployment on EC2

This project is a simple HTML website deployed using Docker and Nginx on an AWS EC2 instance.

## Project Overview
The goal of this project is to containerize a static HTML website using Docker and serve it using Nginx.

## Tools Used
- AWS EC2
- Docker
- Nginx
- HTML

## How it works
1. Build Docker image using Dockerfile
2. Run Nginx container
3. Map port 80 to EC2
4. Access website via EC2 public IP

## Result
A simple static website running inside a Docker container on a cloud server.
